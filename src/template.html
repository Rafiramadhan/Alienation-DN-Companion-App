Sync with your own Google Sheet
  1. Create a new, blank Google Sheet.
  2. In it: Extensions ▸ Apps Script. Delete the sample code, then paste the script — . Save.
  3. Deploy ▸ New deployment ▸ Web app → Execute as: Me, Who has access: Anyone → Deploy and authorise when asked.
  4. Copy the Web app URL (it ends with /exec) and paste it below.
One sheet holds everything — roster, card collections, guild storage and blocklist. The link lets anyone who has it read/write your data, so share it only with people you trust. To use it on another device, connect there with the same URL (tip: the Copy link button once connected).
Already set up before? To update the script: copy it above, paste it over your old code in Apps Script and Save, then Deploy ▸ Manage deployments ▸ ✏️ ▸ Version: New version ▸ Deploy. That keeps the same URL, so you don't need to reconnect.

How this works
Each character keeps their own card collection. Click a slot to select it, then pick a rarity below — or click the selected slot again to cycle Magic → Rare → Epic → Unique → Legend → none. Right-click a slot clears it.
Details shows what the selected card grants at every rarity, with your tier highlighted.
The box under each card is what you paid for it — the strip above the grid totals your spend and counts how many you hold at each rarity.
The Power of Mastery tab is where you type the level of each mastery you have upgraded.
Collections and mastery levels save with the rest of your roster, and sync to your Google Sheet when one is connected (its Cards tab).
